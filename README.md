# ASP.NET Core E-Commerce Backend API

## Project Overview

A RESTful E-Commerce Backend API developed using ASP.NET Core, Entity Framework Core, and MySQL.

## Main Features

- Product management
- Customer management
- Category management
- Order management
- Order items management
- Payment management
- CRUD operations
- Database relationships
- Asynchronous programming

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- MySQL
- Swagger / OpenAPI
- Git and GitHub

## Project Goal

To develop a reliable and maintainable backend system that manages e-commerce operations through RESTful API endpoints.
